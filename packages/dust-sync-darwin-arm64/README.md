# @midnight-wallet-cli/dust-sync-darwin-arm64

Prebuilt native `dust-sync` sidecar for **darwin-arm64**, an optional accelerator for [midnight-wallet-cli](https://www.npmjs.com/package/midnight-wallet-cli). Installed automatically as an optional dependency on matching platforms; the CLI falls back to a bundled WASM reader when it is absent. Do not install directly.
